# 设计 & 规格：查找与替换（v1.4.0）

## Problem

MDPad（v2-fluent）缺少查找/替换能力。需求：

- **查找**：下一个、上一个、大小写敏感（单选框）、匹配计数
- **替换**：替换当前、全部替换
- 查找与替换**共用一个窗口**

## Context

- 编辑器为 `QTextEdit`（Consolas 11），文档模型 `QTextDocument`
- 对话框惯例：`MessageBoxBase` 模态（帮助/保存确认），模态会阻塞编辑——不适合查找替换
- 通知惯例：`MainWindow.notify` → Fluent InfoBar（右上角）
- 快捷键惯例：`QShortcut` 注册于主窗口；F2/F3/F4 已占用视图模式
- 持久化：`QSettings`（本次不新增持久化状态，保持最小）
- 打包：PyInstaller 跟随 import 自动收集新模块，无需改 `pack/MDPad.spec`

## Options Considered

### Option A：非模态浮动工具窗口（推荐）
`QDialog` + `Qt.Tool` 标志，`show()` 而非 `exec()`；单窗口内**查找行 + 替换行同时可见**（无标签页切换）。**视觉与帮助/保存确认对话框一致**：复用其卡片样式（`FluentStyleSheet.DIALOG` + `#centerWidget` QFrame + 同参数投影 + `SubtitleLabel` 标题），仅去掉模态遮罩（`windowMask` + 全屏几何），因此不遮挡/不压暗编辑器。

- 工作流：Ctrl+F 打开 → 输入即计数 → 回车/F3 下一个 → 替换/全部替换
- Pros：编辑器保持可交互（现代编辑器标准）；替换与查找同屏零切换；不侵入主窗口布局；实现独立成模块
- Cons：需自行处理关闭语义（隐藏而非销毁）、Esc、焦点；比模态多少量代码
- Risk：低——`QTextDocument.find` 为 Qt 原生能力

### Option B：模态 MessageBoxBase 对话框
复用现有 `MessageBoxBase` 模式，改动最小。

- Pros：与帮助/保存确认对话框视觉一致
- Cons：模态期间无法点入编辑器编辑；替换操作须频繁开关窗口；体验接近旧版记事本
- Risk：UX 明显落后于同类编辑器，返工概率高

### Option C：主窗口内嵌查找栏（浏览器 Ctrl+F 样式）
在工具栏下方嵌入一条可显隐的查找栏，替换行折叠展开。

- Pros：上下文最连续，无独立窗口
- Cons：改动主窗口布局与状态机；"共用一个窗口"需求下实现成本最高；与现有"对话框"形态割裂
- Risk：中——布局/显隐/焦点管理复杂度最高

## Recommended: Option A

理由：用户明确"共用一个窗口"→ 单个浮动窗口最贴切；非模态保证替换时编辑器可交互；独立模块便于测试与后续维护。

### 交互约定（规格）

**打开**
- Ctrl+F / 工具栏放大镜按钮：打开（或聚焦已打开的）查找窗口
- 打开时若编辑器有选中文本 → 自动填入查找框并全选（可直接覆盖输入）
- 位置**始终居中**于主窗口：主窗口移动/缩放时跟随重居中（eventFilter 同步几何）
- **实时跟随主窗口尺寸**：卡片宽度（0.6 比例，保底 620）与字体缩放随主窗缩放即时更新（基准字体快照 + 目标系数整体重算，无累积漂移），窗口双向收缩/放大
- Esc / 关闭按钮：隐藏窗口（保留查找词等状态，不销毁）

**查找**
- 查找框输入即刷新计数（"N 处" / "无匹配"）
- 回车 = 下一个；Shift+回车 = 上一个；Ctrl+G / Ctrl+Shift+G 在窗口内外均生效（F3 已被"预览模式"占用，不复用）
- 从当前光标位置向后/向前搜索；到文档末尾/开头自动**循环**，循环时 InfoBar 提示一次
- 当前选中文本等于查找词时，下一个/上一个跳过当前匹配，避免原地打转
- 大小写敏感：单个单选框「区分大小写」，选中即敏感，默认不选中（不敏感）
- 计数 = 全文档不重叠匹配数，随查找词、大小写选项、文档内容变化实时刷新

**替换**
- 「替换」：替换当前选中的匹配，随后自动跳到下一个匹配
- 「全部替换」：从文档开头统计全部匹配并替换，InfoBar 报告"已替换 N 处"；替换文本含查找词时不会死循环（先收集位置、从后往前替换）
- 查找词为空时替换按钮禁用

**非目标**（本期不做）：正则、整词匹配、多行匹配、全文高亮、替换模式标签页。

### 边界情况

| 场景 | 行为 |
|---|---|
| 查找词为空 | 计数显示提示，替换按钮禁用；回车/F3 只聚焦查找框 |
| 文档无匹配 | 计数"无匹配"，查找不移动光标 |
| 选中文本含换行 | 查找框为单行输入，按普通文本查找 |
| 文档在窗口打开时被编辑 | 计数随 textChanged 刷新；查找始终从当前光标重算 |
| 替换后查找词仍在替换文本中 | 全部替换按反向位置替换，天然免疫自引用 |
| 窗口打开时替换全部 | 触发 textChanged → 计数自动刷新为新文档状态 |

## Implementation Plan（增量切片）

1. **`mdpad/search.py`（新）**：`FindReplaceDialog(QDialog)`——单窗口 UI（卡片样式对齐 MessageBoxBase）+ 全部查找/替换/计数逻辑（纯操作 `QTextEdit`，可独立测试）
2. **`mdpad/main_window.py`**：工具栏 SEARCH 按钮；Ctrl+F / Ctrl+G / Ctrl+Shift+G 快捷键；对话框懒加载生命周期
3. **`mdpad/dialogs.py` + `mdpad/__init__.py`**：快捷键帮助表新增 3 项；版本号 1.3.0 → 1.4.0；发布说明更新
4. **验证**：offscreen 行为测试（计数/大小写/循环/替换当前/全部替换）+ 真实启动冒烟

## Verification / Acceptance

- 行为测试断言：计数正确（含大小写切换）、下一个/上一个定位与循环、替换当前后自动推进、全部替换数量与文档结果正确、空查询禁用替换
- 应用可正常启动，Ctrl+F 弹出窗口，无回归
